# PyTorch 社区 Benchmark 106 模型说明

## 概述

本文档说明 NPU Benchmark 看板使用的 106 个模型集合。

该模型集合对齐 PyTorch 社区 dashboard 的模型范围，用于在清晰、稳定的模型口径下展示和对比 NPU 后端的 benchmark 结果。

## 106 个模型如何得来

这 106 个模型来自 PyTorch 社区 dashboard 当前覆盖的模型列表。

整理流程如下：

1. 从 PyTorch 社区 dashboard 整理模型名清单。
2. 对模型名做最小规范化处理，例如将 Markdown 中转义的 `\_` 还原为 `_`。
3. 将规范化后的模型名与看板维护表中的 `model` 列做精确匹配。
4. 命中的模型作为当前 Benchmark 看板的社区对齐模型集合。

当前 Benchmark 模型集合共包含 **106 个模型**。

## 来源套件分布

106 个模型来自三个 benchmark 套件：

| Suite | 数量 | 主要覆盖内容 |
| --- | ---: | --- |
| `torchbench` | 58 | PyTorch 真实模型、经典视觉模型、科学计算、推荐、强化学习、GNN、多模态、音频和视觉任务 |
| `huggingface` | 30 | Transformer NLP、LLM、seq2seq 和语音模型 |
| `timm_models` | 18 | 图像分类 backbone，包括 CNN、ViT、Swin、ConvNeXt、EfficientNet 等 |

## 维护规则

Benchmark 看板模型集合应与 PyTorch 社区 dashboard 模型列表保持对齐。

推荐维护流程：

1. 以 PyTorch 社区 dashboard 模型列表作为来源。
2. 当社区 dashboard 模型列表变化时，刷新当前模型集合。
3. 保持模型名稳定，只进行必要的最小规范化处理。
4. 结果数据应记录测试日期、PyTorch 相关包版本、`torch_npu` 包版本或 commit，以及 benchmark 代码 commit。
5. 保持看板模型范围清晰，确保不同日期之间的结果可比较。
